# /config — التهيئة والنشر

- بيئات النشر (dev / staging / production) لكل إقليم خوادم.
- تعريفات CI/CD: اختبارات `/shared` الحتمية + مدقق التعريفات + فحوص ميزانيات الأصول — الأخضر شرط الدمج.
- مخططات Remote Config ونسخ التراجع (Rollback) — انظر `../docs/ONLINE_ARCHITECTURE.md` §7.

لا أسرار (مفاتيح/كلمات مرور) في هذا المجلد أبداً — تُدار عبر مخازن أسرار البيئة.

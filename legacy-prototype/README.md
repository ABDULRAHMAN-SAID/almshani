# النموذج الأولي — Legacy Prototype

هذا هو النموذج الأولي الكامل للعبة «قائد الحشود» بصيغته الأصلية: عدّاء حشود 3D بملف واحد (Three.js r128) — أربع بيئات، زعماء، خريطة مستويات ونجوم، ومتجر ترقيات محلي.

**حالته**: محفوظ عمداً ولا يُحذف.

- **مرجع تقني**: خضع لتدقيق كامل في `../docs/ONLINE_ARCHITECTURE.md` §1 — منه أخذنا أنماط InstancedMesh للحشود، القتال بنبضات ثابتة، والتوليد الحتمي بالبذرة.
- **بذرة طور البعثات (PvE)**: محتواه (مسار متعرج، بوابات مضاعفات، زعماء، بيئات) يُعاد بناؤه في المرحلة 4 كطور «البعثات» داخل اللعبة الإنتاجية — انظر `../docs/ARENA_ROAD.md` §7 و`../docs/ROADMAP.md`.
- **دليل دراسته الكامل**: `../docs/game-guide.html`.

## التشغيل

افتح `index.html` مباشرة أو عبر خادم محلي (`python3 -m http.server`). يعمل دون إنترنت عبر النسخة المحلية `lib/three.min.js`.

> ⚠️ لا يُبنى عليه أي كود إنتاجي جديد — التطوير الجديد في `/client` و`/server` و`/shared`.

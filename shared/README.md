# /shared — قلب اللعبة المشترك

الكود والبيانات المشتركة بين العميل والخادم. **يُبنى أولاً ويُختبر بلا رندر.**

## المحتوى

- `definitions/` — تعريفات اللعبة Data-Driven (المصدر الوحيد للأرقام؛ لا أرقام قتالية داخل أي كود):
  - `units/*.json` — وحدة لكل ملف (مواصفة الحقول في `../docs/UNIT_SYSTEM.md` §9). البذرة الحالية: وحدات الشريحة العمودية الاثنتا عشرة.
  - `commanders/*.json` — القادة (سلبية + مهارة).
  - `arenas/*.json` — الساحات: أبعاد، قطاعات، تضاريس، قيم CP والمؤقتات والنقاط.
  - `economy.json` — العملات، مكافآت الجولات، كلف الترقية.
  - `locales/{ar,en}.json` — كل نصوص اللعبة بمفاتيح (قاعدة «لا نص داخل كود»).
- `simulation/` *(يُنشأ في المرحلة 1)* — مكتبة المحاكاة الحتمية: خطوة ثابتة 20Hz، نقطة ثابتة/أعداد صحيحة، نفس البذرة والنوايا ⟹ نفس النتيجة على كل منصة. تُجمَّع للعميل (Unity/C#‎) وخادم الجولة معاً.
- `protocol/` *(المرحلة 1)* — عقود الشبكة: رسائل النوايا (نشر/Rally/استسلام) وSnapshots/Deltas.

## القواعد

1. لا مرجع لأي API عرض (Unity/Three) هنا إطلاقاً.
2. كل تعديل تعريف يمر بمدقق `/tools`‏ (Schema + حدود منطقية) في CI.
3. أي حقل رقمي قابل للتظليل عبر Remote Config — سمِّ الحقول بثبات.

# قائد الحشود ⚔️ — Warlord: Crowd Commander

لعبة موبايل أونلاين قيد البناء من نوع **بناء الإمبراطوريات (4X-Builder)**: معقل بشري تحت الأرض تبنيه وتطوّره وتجنّد فيالقه — ثم تختبر جيشك في **التحدي الأونلاين**: معارك ساحة فورية 1v1 (قطاعات، نقاط قيادة، فرق تفقد أفرادها أمامك) بخادم حاكم ومحاكاة حتمية. الهرم: 80% بناء وتطوير · 15% تحدي PvP · 5% مهام يومية (منها «وادي الحشود»).

> **ابدأ من هنا**: [`docs/EMPIRE_CORE.md`](docs/EMPIRE_CORE.md) (قلب الإمبراطورية) ثم بقية وثائق التصميم في [`/docs`](docs/GAME_VISION.md).

## تشغيل الشريحة العمودية (PvP أونلاين)

```
npm install
npm run build     # يبني العميل (Three.js) والخادم الحاكم
npm start         # ثم افتح http://localhost:8080 من جهازين/نافذتين
```

لاعبان يدخلان الطابور يتواءمان فوراً؛ اللاعب الوحيد يُواجه **بوتاً معلَناً** بعد ثوانٍ. الخادم هو مصدر الحقيقة الوحيد: العميل يرسل نوايا فقط، والمحاكاة الحتمية المشتركة (`/shared/simulation`) تعمل على الطرفين بتطابق بتّي يُفحص بتجزئات دورية.

```
npm run test:sim  # 32 فحص محاكاة Headless (حتمية، كاونترات، إعادة تشغيل من سجل الأوامر)
npm run sim -- 80 # توازن جماعي: 80 مباراة بوت-ضد-بوت بتقرير معدلات فوز الوحدات
npm run typecheck
```

## تجربة النموذج الأولي

```
cd legacy-prototype && python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` — أو افتح `legacy-prototype/index.html` مباشرة (يعمل دون إنترنت). دليله الدراسي الكامل: `docs/game-guide.html`.

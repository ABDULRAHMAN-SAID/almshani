# قائد الحشود ⚔️

لعبة 3D من نوع «عدّاء الحشود» بعناصر RPG تعمل في المتصفح: تقود جيشاً أزرق عبر وديان متعرّجة، تعبر بوابات المضاعفات، تراوغ المطارق والنيازك، تسحق الزعيم، ثم تحطّم قلعة العدو — وتعود لترقّي جيشك بالذهب.

**A 3D crowd-runner battle game with RPG progression** — winding paths across four biomes, multiplier gates, swinging hammer traps, ambushes, bosses (mega boss every 5th level), star ratings, a level map, and a persistent gold/upgrade economy.

## المزايا

- **أربع بيئات تتناوب كل مستوى**: الصحراء 🏜️ · الثلوج 🌨️ (ثلج متساقط) · البراكين 🌋 (نيازك تسقط عليك!) · الغابة الماطرة ⛈️ (مطر وبرق ورعد)
- **مسار متعرّج** يختلف انحناؤه في كل مستوى — والبوابات والأعداء يتبعونه
- **زعيم يحرس كل قلعة**: يضرب الأرض دورياً فيسحق جزءاً من جيشك، وكل خامس مستوى «زعيم أسطوري» أضخم وأشرس 👑
- **أحداث وعوائق**: مطارق متأرجحة تهرس من يمر تحتها، كمائن حمراء تركض نحوك، نيازك بدائرة إنذار
- **نظام RPG دائم**: ذهب من كل مستوى + متجر ترقيات (قوة الجندي ⚔️، جيش البداية 🛡️، الدروع 🪖، مضاعف الذهب 💰) + بطل ذهبي يحمل الراية
- **نجوم وخريطة حملة**: حتى 3 نجوم لكل مستوى حسب حجم الناجين، وخريطة لإعادة أي مستوى
- **جنود مفصّلون**: خوذة وعرف ودرع ورمح ووجه — بألوان قمم مدموجة في هندسة واحدة للحفاظ على الأداء (InstancedMesh)

## اللعب / How to play

- **اسحب يميناً ويساراً** (لمس أو فأرة، أو الأسهم/WASD) لتوجيه الجيش.
- البوابات الزرقاء والذهبية تزيدك، والحمراء (−، ÷) تنقصك.
- المرور تحت المطرقة المتأرجحة يطحن جنودك — راوغها من الجانب.
- عند الزعيم: جيشك يهاجمه تلقائياً وهو يقفز ويضرب — اصمد حتى يسقط.
- صفّر عداد القلعة لتفوز. النجوم بنسبة الناجين إلى صحة القلعة.

## التشغيل / Run

افتح `index.html` مباشرة، أو:

```
python3 -m http.server 8000
```

المحرك: [Three.js](https://threejs.org) r128 من CDN مع نسخة احتياطية محلية في `lib/three.min.js` — تعمل دون إنترنت. التقدم (المستوى، الذهب، الترقيات، النجوم) يُحفظ محلياً في المتصفح.

| الملف | الوصف |
|---|---|
| `index.html` | لعبة قائد الحشود كاملة |
| `lib/three.min.js` | Three.js 0.128.0 للتشغيل دون إنترنت |
| `tahaddi/index.html` | لعبة «تحدي — عالم المعرفة» (مشروع آخر في نفس المستودع) |

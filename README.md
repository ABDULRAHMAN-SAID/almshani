# قائد الحشود ⚔️

لعبة 3D من نوع «عدّاء الحشود» (Crowd Runner) تعمل في المتصفح — بنفس فكرة الألعاب الشهيرة: تقود جيشاً أزرق عبر وادٍ صخري، تعبر البوابات التي تضاعف جيشك، تتجنب الفخاخ الحمراء، تسحق جيوش العدو، ثم تحطّم قلعته!

**A 3D browser crowd-runner battle game** — lead a blue army through a canyon, pass multiplier gates (×2, ×3, +99), avoid red traps (−25, ÷2), crush the red army, and besiege the enemy castle.

## اللعب / How to play

- **اسحب يميناً ويساراً** لتوجيه جيشك (يعمل باللمس والفأرة، وأيضاً بالأسهم على لوحة المفاتيح).
- البوابات الزرقاء والذهبية **تزيد** جيشك، والحمراء **تنقصه** — اختر الجهة الأذكى.
- عند ملاقاة الجيش الأحمر تبدأ معركة: يفنى الجنود واحداً بواحد — الجيش الأكبر ينتصر.
- في نهاية الوادي قلعة العدو وفوقها رقم صحتها: كل جندي يضحّي بنفسه ينقصها نقطة. صفّرها لتفوز!

## التشغيل / Run

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

- محرك الرسوميات: [Three.js](https://threejs.org) r128 — يُحمَّل من CDN مع نسخة احتياطية محلية في `lib/three.min.js`، فاللعبة تعمل حتى بدون إنترنت.
- تُحفَظ تقدّمك (المستوى وأفضل جيش) محلياً في المتصفح.
- المستويات مولّدة إجرائياً وتزداد صعوبة مستوى بعد مستوى، وكل مستوى ثابت التوليد — إعادة المحاولة تعطيك نفس التوزيع لتتقنه.

## الملفات / Files

| الملف | الوصف |
|---|---|
| `index.html` | اللعبة كاملة: الواجهة، المحرك، توليد المستويات، الصوت |
| `lib/three.min.js` | نسخة Three.js 0.128.0 الاحتياطية للتشغيل دون إنترنت |

# /client — عميل اللعبة

عميل **الشريحة العمودية** الحالي: TypeScript + Three.js معياري (مسار الويب الموثق في `../docs/ONLINE_ARCHITECTURE.md` §2.2) — قابل للنقل إلى Unity لأن كل منطق اللعبة في `/shared` محايد للعرض، والعميل هنا عرضٌ وإدخال فقط.

مسؤوليته حصراً: العرض والإدخال والواجهة — يقرأ التعريفات من `/shared/definitions`، يشغّل نسخة محاكاة `/shared/simulation` محلياً يخطوها بمدخلات التكّات الواردة من الخادم (مطابقة بتّية تُفحص بتجزئات دورية)، ويرسل **نوايا فقط** (لا يملك أي حقيقة اقتصادية أو قتالية).

## البنية

- `src/main.ts` — توجيه الشاشات وربط الشبكة.
- `src/net.ts` — WebSocket بإعادة اتصال تلقائية.
- `src/screens.ts` — المعسكر، الجيش (اختيار 7 من 12)، الطابور، المواجهة، النتيجة.
- `src/battle/game.ts` — متحكم المباراة: محاكاة محلية + طابور تكّات + استيفاء + تقديم سريع لإعادة الاتصال.
- `src/battle/render.ts` — مشهد Three.js: الساحة والجسر والمقران والفرق بأفرادها.
- `src/battle/hud.ts` — خرزات CP، خانات القيادة، المؤقت، النقاط، عدّادات الفرق.
- `src/battle/input.ts` — سحب الشارة للنشر، Rally، مهارة القائد.
- `src/i18n.ts` — نصوص عربية RTL بمفاتيح (جاهزة للإنجليزية).

## البناء والتشغيل

```
npm run build        # يبني العميل والخادم
npm start            # ثم افتح http://localhost:8080
```

مواصفات الشاشات في `../docs/UI_UX.md` والأسلوب البصري في `../docs/ART_DIRECTION.md`.

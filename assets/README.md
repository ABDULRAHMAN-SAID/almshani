# /assets — مصادر الأصول الخام

ملفات المصدر قبل التصدير للعميل: Blender (نماذج/هياكل)، Substance/PSD (خامات)، WAV (صوت خام).

- التصدير إلى العميل آلي (FBX/glTF + ASTC) عبر سكربتات `/tools` — لا نسخ يدوي.
- كل أصل يلتزم ميزانيات وقائمة فحص `../docs/ART_DIRECTION.md` (§9–§10) قبل الدمج.
- الملفات الثقيلة (>10MB) عبر Git LFS عند تفعيله.

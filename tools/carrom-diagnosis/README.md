# إعادة إنتاج عطل جيب الكيرم

`catick.js` منسوخة حرفيًّا من `tahaddi/index.html` (الدالة `caTick`) بلا أي تعديل،
حتى تكون الأرقام أرقامَ اللعبة نفسها لا أرقام نموذج مبسّط.

```
node repro.js    # الهندسة · الضارب لا يسقط · القطعة تمشي على الحافة فتُبتلع · نفي tunnelling
node repro2.js   # التصويب المثالي بسرعات متدرّجة · مقاسات الفم · شيفرة الخطأ الميتة
node repro3.js   # الاستقرار داخل الفم المرسوم · اللوح الكامل ١٩ قطعة
node repro4.js   # مخروط القبول بالدرجات  (بطيء: ~٦ دقائق)
```

الخلاصة والأرقام في `docs/AUDIT-AND-REFACTOR-PLAN.md` §٤.

# /tools — أدوات التطوير

أدوات داخلية تخدم التوازن والجودة (تُبنى تدريجياً بدءاً من المرحلة 1):

- `validate-definitions/` — مدقق ملفات `/shared/definitions` (Schema + حدود منطقية: لا كلفة 0، لا كاونتر > ×2.5…) — يعمل في CI على كل Commit.
- `sim-runner/` — مشغّل محاكاة Headless: آلاف الجولات بوت-ضد-بوت لقياس التوازن قبل أي رندر (وريث فكرة «المحاكاة المزدوجة» من النموذج الأولي).
- `economy-model/` *(المرحلة 2)* — نموذج أعمار التقدم والدخل اليومي (مدخلاته من `../docs/ECONOMY.md` §7).
- `asset-budget-check/` *(المرحلة 1–2)* — فحص ميزانيات المثلثات/الخامات لكل أصل (`../docs/ART_DIRECTION.md` §9).

## audit-controls.cjs
يفحص كل `onclick`/`onchange`/… في الواجهة ويتحقّق أن الدالّة المستدعاة معرّفة فعلًا.
الزرّ الذي ينادي دالّة غير موجودة لا يفعل شيئًا، والمستخدم يظنّ اللعبة معلّقة.

    node tools/audit-controls.cjs

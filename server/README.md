# /server — الخادم الحاكم

الخادم يملك الحقيقة كلها: حسابات، عملات، نتائج، مواءمة، محاكاة الجولات (`../docs/ONLINE_ARCHITECTURE.md` §3–§7).

## المكوّنان

- `nakama/` *(المرحلة 1)* — طبقة الخدمات فوق **Nakama + PostgreSQL**: هوية وحفظ سحابي، مواءمة، تخزين، لوحات، دردشة، Remote Config.
- `match-server/` *(المرحلة 1)* — خادم الجولة المخصص: يشغّل مكتبة `/shared/simulation` نفسها بخطوة 20Hz، يتحقق من النوايا ويبث Snapshots/Deltas، وينسَّق أفقياً بـ Agones/Kubernetes.

قاعدة ذهبية: أي قيمة تصل من العميل هي **ادّعاء يُفحص**، لا حقيقة.

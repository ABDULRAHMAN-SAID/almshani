# /server — الخادم الحاكم

الخادم يملك الحقيقة كلها: حسابات، عملات، نتائج، مواءمة، محاكاة الجولات (`../docs/ONLINE_ARCHITECTURE.md` §3–§7).

## خادم الشريحة العمودية (الحالي)

Node.js + WebSocket على منفذ واحد (HTTP يقدّم العميل، `/ws` للعبة):

- `src/index.ts` — المدخل: HTTP + WSS + توجيه الرسائل (`/shared/protocol`).
- `src/lobby.ts` — حسابات ضيف (رمز)، حفظ التشكيلة بتصديق، طابور بمواءمة، **بوت معلَن** بعد مهلة الانتظار، جلسة واحدة نشطة للحساب.
- `src/match.ts` — غرفة المباراة: يشغّل `/shared/simulation` بخطوة 20Hz كمصدر حقيقة وحيد، يختم النوايا بالتكّة ويبثها مرتّبة، يقارن تجزئات العملاء بتجزئته (كشف Desync)، يبقي مقعد المنقطع 30 ثانية (إعادة اتصال بتقديم سريع من سجل الأوامر)، ويحفظ سجل كل مباراة (بذرة نظام الإعادات).

متغيرات بيئة: `PORT` · `MATCH_TICK_MS` (تسريع الاختبارات) · `QUEUE_BOT_MS` · `CLIENT_DIR`.

## طريق الإنتاج (المرحلة 1+)

- `nakama/` — طبقة الخدمات فوق **Nakama + PostgreSQL**: هوية وحفظ سحابي، مواءمة، تخزين، لوحات، دردشة، Remote Config — تحل محل ذاكرة `lobby.ts` بنفس العقد.
- `match-server/` — غرف الجولات نفسها منسَّقة أفقياً بـ Agones/Kubernetes.

قاعدة ذهبية: أي قيمة تصل من العميل هي **ادّعاء يُفحص**، لا حقيقة — الهوية تُؤخذ من المقعد لا من الرسالة، وكل نية تصدّقها المحاكاة ذاتها.
